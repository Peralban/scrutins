Carte des députés

Chaque point est un député. Deux députés proches votent de façon proche sur les scrutins retenus. Les axes sont les deux directions qui expliquent le plus les différences de vote (analyse en composantes principales) ; ils n'ont pas d'étiquette propre : seules les distances comptent.

Méthode : matrice députés × scrutins (pour +1, abstention 0, contre −1). Une absence est remplacée par la position moyenne du groupe sur ce scrutin, pour qu'elle ne crée pas de distance artificielle ; seuls les députés ayant au moins 100 votes exprimés (15 par thème) sont placés. Par thème, la carte ne porte que sur les scrutins rattachés au thème (voir la page Thèmes pour les règles). Les axes sont orientés par convention (LFI-NFP à gauche, groupes centraux en haut) : une carte par thème peut ne pas montrer un axe gauche-droite. Les points d'un même groupe se superposent souvent : c'est la discipline de vote.
