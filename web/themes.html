Profil de vote par thème

Part de « pour » parmi les votes exprimés de chaque groupe (pour, contre, abstention), sur les scrutins rattachés au thème. Un clic sur un thème ouvre ses scrutins dans l'hémicycle.

0 % pour100 % pourcellule grise : moins de 30 votes exprimés
Le thème d'un scrutin est déduit par mots-clés dans l'intitulé du texte de loi concerné ; un scrutin peut avoir plusieurs thèmes ou aucun. C'est une aide de lecture, pas une classification officielle. Sur les amendements, « pour » dépend de qui les dépose : préférer les votes sur l'ensemble.
